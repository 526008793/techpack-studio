制单助手 v1.0.10

安装后，点击桌面“制单助手”打开。
新版使用 ZHH 字母图标，覆盖安装时会重建桌面和开始菜单快捷方式。

第一次建议点击“查看 P4541 示例”，无需配置模型即可体验核对、改尺寸和导出 Excel。

处理新的 PDF：
1. 打开左下角“模型与 API 设置”，填写支持图片输入的服务地址、模型名称和 API Key。
2. 选择新 PDF，使用内置模板，或选择自己的服装 Excel 模板。
3. 点击“识别并整理资料”。此时 PDF 页面和文字会发送到你配置的模型服务。
4. 核对资料、面辅料、尺寸及图片裁剪范围。CAD相关页和尺寸页保留中英对照，其余填写区域使用中文；款号、品牌、人名、尺码和色号等原始标识保留。
   CAD 中文按英文标注位置写在附近空白处，使用蓝色可编辑文本框。图片参考页可预览、展开修改译文；导出后可在 Excel/WPS 中编辑、拖动。
5. 点击“生成 Excel 制单”，选择新文件保存位置。
6. 用 Excel 或 WPS 打开成品，打印前检查打印预览。

已内置：面料分行、增加独立衬并同步实际存在的对应表、绣章不标黄、客人意见或邮件页内容与图片保留、风险评估会指导意见原文保留。已匹配的工作表设置 A4 页面大小和分页，最后在 Excel 或 WPS 中打印。App 不提供打印功能。
数量搭配及打样要求页总计下方的说明，保留模板原文、格式、合并和行高；配色增行时整段下移，其中原有英文也不改写。
旧资料缺少中文时请补充对应中文字段；未知英文色名保留原色号并提示确认，不猜颜色，也不把整段英文填进中文页。

没有提供的规格、数量、部位等显示“待确认”，不会自行推算。
模型可能识别错误，请特别核对尺寸、公差、数量、配色和唛头占位内容。

“保存资料”可以把核对内容另存 JSON，以后“导入已存资料”继续修改。
相同 PDF 的识别结果会本地缓存；手动填写、加载示例、导入资料和导出 Excel 均不调用模型。

模板范围：支持内置十一页模板，以及按常见服装制单标题、字段标签和表头识别的自定义模板。自定义模板可增减工作表、改名、移动栏目或调整列顺序，保留原表数量、名称和顺序。衣服、裤子的图片、尺寸和材料按新 PDF 填写，不沿用模板旧款数据。
材料数量增加时自动扩行，按原字号调整换行和行高，有新内容的隐藏配色列会显示。
无法明确识别的工作表保留原内容和页面设置。不保证任意无标签自由排版都能识别。PDF 未提供的 CAD 图显示待确认，不生成虚构图。
使用内置模板或 .xlsx 文件无需安装 Excel。
支持直接选择 .xls 和 .xlsx 模板，App 内置转换组件，原文件不覆盖，无需安装 Office。
WPS 内嵌图片公式在其他转换器中可能失效，请在成品中核对图片。

CAD 标注会检查英文、服装轮廓、引线和其他译文是否占位。译文只写在图上，不再补写图下工艺、标签规格或未放置译文；附近留白不足或裁剪遗漏时提示人工补充。CAD 图片区不保留单元格框线，页头框线保留，材料表仍正常填写。
“图片参考”逐条显示“已上图”“已翻译，未上图”“缺少中文译文”，未完成项自动展开。密集图会扩展右侧译文区并保留对应英文，中文仍可编辑。缺少中文、原图或标注未完整上图时仍可先生成文件，再到 Excel/WPS 中手工修改。
旧版资料没有图中标注位置时，请重新识别原 PDF；旧数据仍可导入。

推理强度默认 xhigh，可在模型设置中修改，所选模型和服务须支持该强度。
模板栏目识别在本地完成，不额外调用模型。模型请求使用系统代理设置。

本版本面向 Windows x64（Intel/AMD）电脑。
API Key 可以只在当前会话使用；选择记住时使用 Windows 系统加密，不会写入 Excel 或资料 JSON。

留底卡下方贴样区域不自动填写面料说明或“实样粘贴区”，原合并、行高和无框线样式保留。
原模板计算和跨表引用公式保留到新文件，新增行延续公式并调整引用；外部文件引用保持原样。只有旧款图片公式继续按新 PDF 图片替换。
原本没有框线的单元格不添加框线。

缓存目录：左下角“清除缓存”可直接清理识别缓存，模型设置中可更改位置或恢复默认。默认缓存在安装目录下的techpack-studio-cache专用文件夹（Mac为App所在目录），旧版默认缓存自动迁移；清理后同一PDF重新调用AI。
Windows真正卸载会删除安装目录、所有用过的专用缓存目录及其中全部文件、API Key和模型配置；覆盖升级保留。Mac在设置中使用“卸载并清除本机数据”，退出后删除App、日志、配置和专用缓存目录。已导出的Excel及缓存专用目录之外的文件保留。
服务返回408/504是上游请求超时，失败结果不写缓存，可直接重试；反复超时可调整推理强度或请服务商按request_id检查限制。默认仍使用xhigh。
