制单助手 v1.0.5

安装后，点击桌面“制单助手”打开。
新版使用 ZHH 字母图标，覆盖安装时会重建桌面和开始菜单快捷方式。

第一次建议点击“查看 P4541 示例”，无需配置模型即可体验核对、改尺寸和导出 Excel。

处理新的 PDF：
1. 打开左下角“模型与 API 设置”，填写支持图片输入的服务地址、模型名称和 API Key。
2. 选择新 PDF，使用内置模板，或选择自己的服装 Excel 模板。
3. 点击“识别并整理资料”。此时 PDF 页面和文字会发送到你配置的模型服务。
4. 核对中英资料、面辅料、尺寸及图片裁剪范围。
   CAD 中文按英文标注位置写在附近空白处，使用蓝色可编辑文本框。图片参考页可预览、展开修改译文；导出后可在 Excel/WPS 中编辑、拖动。
5. 点击“生成 Excel 制单”，选择新文件保存位置。
6. 用 Excel 或 WPS 打开成品，打印前检查打印预览。

已内置：面料分行、增加独立衬并同步实际存在的对应表、绣章不标黄、客人意见或邮件页内容与图片保留、风险评估会指导意见原文保留。已匹配的工作表按 A4 单页打印。

没有提供的规格、数量、部位等显示“待确认”，不会自行推算。
模型可能识别错误，请特别核对尺寸、公差、数量、配色和唛头占位内容。

“保存资料”可以把核对内容另存 JSON，以后“导入已存资料”继续修改。
相同 PDF 的识别结果会本地缓存；手动填写、加载示例、导入资料和导出 Excel 均不调用模型。

模板范围：支持内置十一页模板，以及按常见服装制单标题、字段标签和表头识别的自定义模板。自定义模板可增减工作表、改名、移动栏目或调整列顺序，保留原表数量、名称和顺序。衣服、裤子的图片、尺寸和材料按新 PDF 填写，不沿用模板旧款数据。
材料数量增加时自动扩行，按原字号调整换行和行高，有新内容的隐藏配色列会显示。
无法明确识别的工作表保留原内容和打印设置，导出页提示“未自动填写”；无明确标签的旧值或无法读取的图片、公式也会提示核对。不保证任意无标签自由排版都能识别。PDF 未提供的 CAD 图显示待确认，不生成虚构图。
使用内置模板或 .xlsx 文件无需安装 Excel。
旧 .xls 自动转换需要已安装 Microsoft Excel 或 LibreOffice；也可用 WPS 先另存为 .xlsx。
WPS 内嵌图片公式在其他转换器中可能失效，请核对导出提示。

CAD 标注会检查英文、服装轮廓、引线和其他译文是否占位。附近留白不足或裁剪遗漏的标注，在导出页提示具体项目，并在图下保留文字，需人工调整。已完整写到图中的工艺不再在图下重复，材料表仍正常填写。
旧版资料没有图中标注位置时，请重新识别原 PDF；旧数据仍可导入，文字说明会保留。

推理强度默认 xhigh，可在模型设置中修改，所选模型和服务须支持该强度。
模板栏目识别在本地完成，不额外调用模型。模型请求使用系统代理设置。
左侧“已保存的模板规则”支持＋新增、双击修改、右键删除并保存，目前是核对清单，改字不会自动改变生成逻辑。

本版本面向 Windows x64（Intel/AMD）电脑。
API Key 可以只在当前会话使用；选择记住时使用 Windows 系统加密，不会写入 Excel 或资料 JSON。
